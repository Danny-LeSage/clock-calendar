Calendars

    One-time setup (about 3 minutes). After this, connecting is one click.

    1. Create a Google Cloud project (any name).
    2. Turn on the Google Calendar API for it.
    3. Set up the consent screen: choose External, then add your own Google account under Audience → Test users.
    4. Create an OAuth client: type Web application, and add this as an authorised redirect URI:
    5. Paste the client ID and secret it gives you:

    Use your Apple ID email and an app-specific password. Your normal password won't work. Make one at account.apple.com → Sign-In and Security → App-Specific Passwords.

    iCloud and calendar links work in the version running on your computer.

    Read-only. Works with any calendar that has an .ics or webcal link (Outlook, school or team calendars, …).
